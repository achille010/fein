### Core Functionality

1. **Multi-Page Navigation**: Clean navigation between different sections of the site
2. **Visual Design**: Rich imagery including chef photos, client testimonials, food items, and promotional graphics
3. **Responsive Styling**: CSS for layout, typography, and visual polish
4. **Form Elements**: Booking and contact forms for user interaction

### Page Structure

The website includes:
1. A hero section with main visuals (main.jpg, combo.png)

### Key Concepts Demonstrated

- **Semantic HTML**: Clean, structured markup for accessibility and SEO

- **Multi-Page Structure**: Traditional website navigation across multiple HTML files
- **Image Integration**: Effective use of imagery throughout the site
- **Form Design**: User input forms for booking and contact

## Installation

1. Clone the repository:
```bash
git clone https://github.com/achille010/fein.git
cd fein
```

2. Open `home.html` in your browser:
```bash
# Simply double-click home.html or use a local server
npx live-server
```

## Limitations

- Static pages only (no backend processing)
- Forms are frontend only (no submission handling)
- No JavaScript interactivity
- No responsive breakpoints for mobile optimization

This is intentionally simple to demonstrate clean HTML/CSS web design.

## Requirements

- Web browser
- No build tools or dependencies required
